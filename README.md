# Curso de Medicina em arquitetura de portais

Repositório de trabalho para a idealização de um curso de Medicina inspirado na engenharia operacional de grandes parques temáticos (fluxo, capacidade, portais, narrativa e feedback), em conformidade com a Resolução CNE/CES nº 3/2025 (DCN de Medicina), e para sua aproximação com o curso de Medicina da Unidavi.
